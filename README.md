# 🛒 Point of Sale (POS) Desktop Application  
A Windows Forms Point of Sale system built in C# with SQL Server.  
This project includes **Product**, **Customer**, and **Order** modules with CRUD operations.  
Advanced features are included for **Products** and **Customers**, while **Orders** contain only basic CRUD.

---

## ⭐ Features Overview

### 🔹 Product Module (Advanced + CRUD)
- Add new products  
- Update existing products  
- Delete products  
- View all products  
- Search products by name  
- Auto-generate Product ID  
- Search by price range
- Search by price difference
- Search by price  
- Show product list in DataGridView  

---

### 🔹 Customer Module (Advanced + CRUD)
- Add new customer  
- Update customer details  
- Delete customer  
- View all customers  
- Search/filter customers by name  
- Phone number validation  
- Show customers in DataGridView
- Search by address
- Serach by age
- Search by Contact

---

### 🔹 Order Module (Basic CRUD Only)
- Create an order  
- Update order  
- Delete order  
- View all orders  
- Standard fields:  
  - Order ID  
  - Customer  
  - Product  
  - Quantity  
  - Total price (basic calculation)
